# SDK PHP kLog

Cliente de ingesta REST para PHP 8.1+.

```bash
composer install
composer test
```

La raíz del repo también corre `lint` (`php -l`), `test` y `build` con `npm run check`.

Paquete: `klog/sdk-php`. Solo envía eventos; no usa GraphQL. El token no debe registrarse en logs.

Responder en español.
