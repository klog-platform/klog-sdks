# SDK Java kLog

Cliente de ingesta REST para Java 17+.

```bash
mvn test
mvn package
```

La raíz del repo también corre `lint`, `test` y `build` con `npm run check`.

Artefacto: `com.kriverdevice:klog-sdk` (paquetes `com.kriverdevice.klog`). Solo envía eventos; no usa GraphQL. El token no debe registrarse en logs.

Responder en español.
