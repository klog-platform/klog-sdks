# SDK ESP32 kLog

Biblioteca C/C++ de ingesta REST para ESP32. Misma API pública para:

- **Arduino** (`library.properties`, ejemplos `.ino`)
- **ESP-IDF / Espressif** (`CMakeLists.txt`, `idf_component.yml`)

```bash
# Pruebas host (sin hardware): requieren gcc
make -C test/host test
```

No usa GraphQL. El token no debe imprimirse en logs.

Responder en español.
